# 8. Метрики задачи мультиклассификации и их модернизация

В мультиклассовой классификации (когда целевая переменная $Y$ может принимать более двух значений, например, $Y \in \{A, B, C, D\}$) мы не можем использовать простую матрицу ошибок $2\times 2$. Мы используем матрицу ошибок $K \times K$ (где $K$ — число классов), а затем применяем методы усреднения.

## 1. Модернизация метрик для задачи мультиклассификации

Для оценки качества в мультиклассовой задаче используется подход **"Один против всех" (One-vs-Rest, OvR)**. Для каждого класса $C_k$:

1.  Мы временно считаем класс $C_k$ — **"Положительным"** (Positive).
2.  Все остальные классы — **"Отрицательными"** (Negative).
3.  Строится локальная матрица ошибок $2\times 2$ (TP, TN, FP, FN) для класса $C_k$.
4.  Вычисляются метрики (Precision, Recall, F1) для класса $C_k$.

После этого метрики для всех $K$ классов усредняются тремя основными способами:

### А. Macro-Averaging (Макро-усреднение)

1.  Вычислить метрику (Precision, Recall или F1) **для каждого класса** независимо.
2.  **Усреднить** полученные $K$ значений.

$$\text{Macro-Metric} = \frac{1}{K} \sum_{k=1}^{K} \text{Metric}_k$$

- **Особенность:** Все классы, независимо от их размера, вносят **равный вклад** в итоговую метрику.
- **Использование:** Идеально подходит, когда **все классы одинаково важны**, и вы хотите, чтобы модель хорошо работала на **маленьких (миноритарных) классах**. Если модель плохо справляется с редким классом, это сильно снизит Macro-метрику.

### Б. Micro-Averaging (Микро-усреднение)

1.  **Суммировать** элементы матрицы ошибок (TP, TN, FP, FN) **по всем классам**.
2.  Вычислить итоговую метрику, используя эти **глобальные суммы**.

$$\text{Micro-Precision} = \frac{\sum_{k=1}^{K} TP_k}{\sum_{k=1}^{K} (TP_k + FP_k)}$$

- **Особенность:** Micro-Precision, Micro-Recall и Micro-F1 **всегда равны** общей **Accuracy** (Точности) в мультиклассовой задаче.
- **Использование:** Доминирующие классы (с большим количеством примеров) вносят **больший вклад**. Подходит для оценки, когда классы **несбалансированы**, но **Accuracy** является приемлемой метрикой (т.е., вы просто хотите общую долю правильных ответов).

### В. Weighted-Averaging (Взвешенное усреднение)

1.  Вычислить метрику для каждого класса.
2.  Усреднить эти значения, используя **долю объектов** каждого класса в общем наборе данных в качестве **веса**.

$$\text{Weighted-Metric} = \sum_{k=1}^{K} \left(\text{Metric}_k \cdot \frac{N_k}{N_{\text{total}}}\right)$$

- **Особенность:** Эта метрика отражает, насколько хорошо модель работает на большей части данных, и часто используется для получения **общей картины производительности** в несбалансированных наборах данных.

## Дополнительная метрика: Log Loss (Логарифмическая функция потерь)

- Log Loss часто используется как **функция потерь** (для обучения) в задачах классификации, поскольку она учитывает **вероятности**, предсказанные моделью, а не только конечную метку.
- Log Loss **сильно штрафует** модель, когда она предсказывает **высокую уверенность** (близко к 1) для **неправильного класса**.
- Log Loss является **дифференцируемой** и лучше подходит для оптимизации, чем негладкие метрики вроде F1.

**Log Loss (для одного примера):**
$$-\left(y \log(\hat{y}) + (1-y) \log(1-\hat{y})\right)$$
где $y$ — истинное значение (0 или 1), $\hat{y}$ — предсказанная вероятность.

Log Loss также может быть обобщена для мультиклассовых задач (известна как **Categorical Cross-Entropy**).
