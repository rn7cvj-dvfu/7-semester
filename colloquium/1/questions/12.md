# 12. Иерархические и аггломеративные методы кластеризации

## 1. Иерархическая кластеризация (Hierarchical Clustering)

Иерархическая кластеризация создает **древовидную структуру** (Дендрограмму), которая отражает иерархию отношений между объектами, а не просто их разделение на $K$ непересекающихся групп.

Иерархические методы делятся на два основных типа:

### А. Аггломеративная кластеризация (Agglomerative / "Снизу вверх")

Это наиболее распространенный подход. Все начинается с того, что каждый объект считается **отдельным кластером**. На каждой итерации объединяются два **наиболее близких** кластера, пока не останется один большой кластер (корень).

1.  **Начало:** $N$ кластеров (каждый объект — свой кластер).
2.  **Повторение:** Найти две ближайшие группы (объекты или кластеры) и **объединить** их в новый кластер.
3.  **Конец:** Остается один кластер.

### Б. Дивизивная кластеризация (Divisive / "Сверху вниз")

Начинается с одного большого кластера (все данные) и на каждой итерации делится на два **наименее похожих** дочерних кластера, пока каждый объект не станет отдельным кластером. Этот метод вычислительно сложнее и используется реже.

## 2. Механизм Аггломеративной кластеризации (Linkage Methods)

Ключевой момент в аггломеративном методе — это определение **расстояния между кластерами** (Linkage Criterion).

| Метод связи (Linkage)                | Описание                                                                                                                                                         | Особенности                                                                                        |
| :----------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------- |
| **Одинарная связь (Single Linkage)** | Расстояние между кластерами — это **минимальное** расстояние между любыми двумя объектами из разных кластеров.                                                   | Склонен к "цепочечному эффекту" (elongated, chain-like clusters).                                  |
| **Полная связь (Complete Linkage)**  | Расстояние между кластерами — это **максимальное** расстояние между любыми двумя объектами из разных кластеров.                                                  | Склонен к созданию компактных, сферических кластеров.                                              |
| **Средняя связь (Average Linkage)**  | Расстояние — **среднее** расстояние между всеми парами объектов из разных кластеров.                                                                             | Более устойчив к выбросам, чем одиночная связь, и часто дает хорошие, сбалансированные результаты. |
| **Метод Уорда (Wards Method)**       | Использует **дисперсию**. Объединяются кластеры, при слиянии которых **минимально увеличивается** общая внутрикластерная сумма квадратов (WCSS) (как в K-means). | Склонен создавать компактные, равномерно распределенные кластеры. Очень популярен.                 |

## 3. Преимущества Иерархической кластеризации

| Преимущество                           | Описание                                                                                                                                                                                                                     |
| :------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Нет необходимости задавать $K$**     | Главное преимущество: нет необходимости заранее определять количество кластеров. Результат — **дендрограмма**, которая позволяет исследователю визуально выбрать оптимальное $K$ (путем "срезания" дерева на нужной высоте). |
| **Информативная визуализация**         | Дендрограмма наглядно показывает **иерархические отношения** между объектами и кластерами.                                                                                                                                   |
| **Возможность иерархического анализа** | Позволяет анализировать данные на **разных уровнях детализации** (от очень мелких групп до очень крупных).                                                                                                                   |
| **Не зависит от инициализации**        | В отличие от K-means, иерархическая кластеризация дает **детерминированный** результат (одинаков при каждом запуске).                                                                                                        |

## 4. Метрики кластеризации

Метрики те же, что и для K-means, поскольку они оценивают **качество** конечного разбиения, а не алгоритм, который его создал.

#### А. Внутренние метрики (Internal Metrics)

Используются, когда истинные метки **неизвестны**.

- **Коэффициент силуэта (Silhouette Score):** Измеряет, насколько хорошо объект соответствует своему кластеру (близко к +1) по сравнению с другими кластерами (близко к -1). Используется для сравнения качества кластеризации с разными $K$.
- **Индекс Дэвиса-Боулдина:** Оценивает компактность и разделенность кластеров (меньшее значение лучше).
- **WCSS (Инерция):** Используется для **метода "Локтя"**, чтобы графически определить оптимальное $K$.

### Б. Внешние метрики (External Metrics)

Используются, когда **истинные метки известны** (для тестирования и сравнения):

- **Скорректированный индекс Рэнда (Adjusted Rand Index, ARI)**
- **V-мера (V-measure)** (гармоническое среднее Однородности и Полноты)

**Метод "Локтя" (Elbow Method):**

Это эмпирический метод для выбора оптимального числа кластеров $K$ с использованием внутренней метрики **WCSS (Инерция)**.

1.  Выполнить кластеризацию K-means (или Wards) для диапазона значений $K$ (например, от 1 до 10).
2.  Построить график зависимости WCSS от $K$.
3.  Оптимальное $K$ находится в точке "изгиба" или "локтя", после которой уменьшение WCSS становится значительно менее резким. Эта точка указывает на то, что добавление дополнительных кластеров не приводит к существенному улучшению качества разбиения.
