## Task практика 28.11

1. Развернуть Airflow (желательно используя Docker).
2. Ознакомиться с [https://openweathermap.org/api](https://openweathermap.org/api) - API Openweathermap. Получить доступ к прогнозу погоды. Выбрать несколько областей (городов) для сбора погоды.
3. Написать скрипт сбора текущего прогноза погоды для данной местности используя python / pandas / requests. **Предобработать** данные и привести в pd.DataFrame.
4. Архитектурно разделить pipeline на следующие части: подключение / сбор / предобработка / сохранение данных (желательно отдельными функциями)
5. Автоматизировать разделенный pipeline при помощи Airflow Python operator. В случае необходимости использовать другие операторы.
6. Убедиться в отсутствии в коде DAG или функций кредов (токены/пароли/ авторизационные данные)
7. Запустить DAG в manual режиме. Проверить что все сохранилось.
8. Настроить для DAG расписание сбора согласно обновлению данных в openweathermap.
9. Добавить логирование в код DAG-а для отслеживания его успешности выполнения (библиотека logging / обычные print)
10. Отправить отчет со скриншотами с выполнениями DAG. Логами. Настроенными кредами и т.д.
