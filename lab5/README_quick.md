# Лабораторная работа №5 - Temperature Monitoring System

Кроссплатформенная система мониторинга температуры с HTTP-сервером и базой данных SQLite.

## Описание

Система состоит из:
- **Симулятора датчика температуры** - генерирует случайные значения температуры и отправляет через виртуальный COM порт
- **HTTP-сервера** - принимает данные с датчика, сохраняет в базу данных SQLite и предоставляет REST API
- **Веб-интерфейса** - отображает текущую температуру и статистику в виде графиков и таблиц

## Возможности

✅ Чтение данных с виртуального COM порта  
✅ Сохранение измерений в базу данных SQLite  
✅ HTTP REST API для получения данных  
✅ Веб-интерфейс с графиками (Chart.js)  
✅ Агрегация данных по часам и дням  
✅ Автоматическая очистка старых данных  
✅ Кроссплатформенность (Windows, Linux, macOS)

## Быстрый старт

### Сборка

```bash
cd src
./build.sh
```

### Запуск

```bash
./run.sh
```

Откройте в браузере: http://localhost:8080

## API Endpoints

- `GET /` - Веб-интерфейс
- `GET /api/current` - Текущая температура
- `GET /api/stats?period=hourly&start=<unix_time>&end=<unix_time>` - Статистика

Подробнее см. [README.md](README.md)
